SHYAM PORTFOLIO - QUICK START

1. Keep index.html, style.css and script.js in the same folder.
2. Open index.html in a browser, or use VS Code Live Server.
3. Add your professional photo at:
   assets/images/profile.jpg
   Recommended: square or portrait crop, JPG or PNG. If you use PNG, update the image src in index.html.
4. Replace the LinkedIn placeholder URL in index.html with your actual LinkedIn profile URL.
5. Review project descriptions and statuses. Only claim completed work that you can demonstrate.
6. Update skills to match your actual hands-on experience.

Run locally in Ubuntu/WSL:
  cd ~/Shyam-Portfolio
  code .
Then right-click index.html in VS Code and choose "Open with Live Server" (if Live Server is installed).
Alternatively, open index.html directly in your browser.

GitHub Pages deployment:
  - Create a public repository named Shyam-Portfolio (or another name).
  - Push these files to the main branch.
  - In GitHub: repository Settings > Pages.
  - Under Build and deployment, choose Deploy from a branch, branch main, folder / (root), then Save.
  - Wait for the Pages deployment and use the published URL in LinkedIn.

NOTE:
The profile photo is intentionally a placeholder. The site shows a stylized "S." fallback until you add your own image.
The skill-bar lengths are visual design elements, not measured proficiency ratings.
